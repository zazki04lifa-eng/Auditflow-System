# AuditFlow Audit Trail Schema (Sprint 5)

**Version:** 1.0  
**Date:** 2026-07-24  
**Status:** Active

---

## Overview

This document defines the data schemas for the Audit Trail system introduced in Sprint 5. The audit trail provides immutable tracking of all user and system activities, enabling full traceability for audit purposes.

## Core Principles

1. **Immutable**: Audit entries cannot be updated or deleted after creation
2. **Non-blocking**: Audit failures don't affect main application features
3. **Schema-first**: All structures defined in `docs/DATA_SCHEMAS.md`
4. **Backward compatible**: Sprint 1-4 functionality unchanged

---

## Data Structures

### AuditEntry

Core audit trail entry recording a single action.

```typescript
interface AuditEntry {
  // Identity
  id: string;                    // Format: audit_timestamp_random
  projectId: string;             // Reference to project
  
  // Action
  type: AuditActionType;         // Action type enum
  timestamp: string;             // ISO 8601 timestamp
  userId: string;                // Who performed the action
  
  // Classification
  source: 'manual' | 'rule-engine' | 'ai' | 'system';
  status: 'active' | 'deleted' | 'restored';
  
  // Entity Reference
  entityType?: 'project' | 'flowchart' | 'wcgw' | 'review' | 'export';
  entityId?: string;
  
  // Content
  summary: string;               // Generated by AuditFormatter
  details: AuditEntryDetails;
}

interface AuditEntryDetails {
  before?: Record<string, unknown>;
  after?: Record<string, unknown>;
  changes?: ChangeSummary[];
  parserMetadata?: ParserMetadata;  // From Sprint 4
  wcgwMetadata?: WCGWMetadata;
  exportMetadata?: ExportMetadata;
}
```

### VersionEntry

Snapshot of project state at a point in time.

```typescript
interface VersionEntry {
  id: string;                    // Format: version_timestamp_random
  projectId: string;
  versionNumber: number;         // Per-project, sequential
  timestamp: string;             // ISO 8601
  userId: string;
  action: AuditActionType;
  changeSummary: ChangeSummary[];
  snapshot?: any;                // Full state (if under size limit)
  snapshotOmitted: boolean;      // True if snapshot too large
}
```

### ApprovalEntry

Records approval workflow actions.

```typescript
interface ApprovalEntry {
  id: string;                    // Format: approval_timestamp_random
  projectId: string;
  status: 'submitted' | 'approved' | 'rejected' | 'needs_revision';
  timestamp: string;             // ISO 8601
  userId: string;
  reviewerId?: string;
  comments?: string;
  approvalData?: any;
}
```

### AuditActionType

Complete list of trackable actions.

```typescript
type AuditActionType = 
  // Session
  | 'session.start' | 'session.end'
  // Project
  | 'project.create' | 'project.update' | 'project.delete'
  // Understanding Business
  | 'understanding-business.update'
  // Flowchart
  | 'flowchart.generate' | 'flowchart.auto-generate' | 'flowchart.manual-edit'
  | 'flowchart.lock' | 'flowchart.unlock'
  // Parser
  | 'parser.run'
  // WCGW
  | 'wcgw.detect' | 'wcgw.add' | 'wcgw.remove' | 'wcgw.update'
  // Review
  | 'review.submit' | 'review.approve' | 'review.reject' | 'review.revise'
  // Export
  | 'export.report' | 'export.flowchart'
  // Settings
  | 'settings.update' | 'knowledgebase.update';
```

## Storage

### localStorage Structure

```javascript
{
  'auditflow_audit_trail': {
    entries: AuditEntry[],      // All audit entries
    versions: VersionEntry[],    // Version history
    approvals: ApprovalEntry[]   // Approval history
  }
}
```

### Size Limits

- Maximum entries: 10,000 (auto-pruned)
- Snapshot max size: 100KB (larger snapshots omitted)
- Pruning: 90 days default retention

## Service API

### AuditTrail Module

```javascript
// Core operations
AuditTrail.record(action, context)           // Record new entry
AuditTrail.getTimeline(projectId, filters)   // Query with filters
AuditTrail.getVersions(projectId)            // Get version history
AuditTrail.getApprovals(projectId)           // Get approval history
AuditTrail.exportData(projectId)             // Export for reporting

// Maintenance
AuditTrail.prune(maxAge)                     // Cleanup old entries

// Dashboard
AuditTrail.getRecentActivities(limit)        // Cross-project activities
AuditTrail.getStatistics(projectId)          // Audit statistics
```

### ActivityTimeline Component

```javascript
// Render timeline in container
ActivityTimeline.render(containerId, options);

// Options
{
  projectId: 'proj-123',    // Filter by project
  mode: 'recent',           // 'recent' for cross-project
  limit: 10,                // Max entries to show
  showDetails: false,       // Show change details
  showFilter: false,        // Show filter dropdown
  title: 'Activity Timeline',
  emptyMessage: 'No activities found'
}
```

### AuditFormatter Module

```javascript
// Generate consistent summary
AuditFormatter.format(action, context);

// Format change for version history
AuditFormatter.formatChange(entityType, changeType, details);

// Format parser metadata summary
AuditFormatter.formatParserMetadata(parserMetadata);
```

## Integration Points

### Using Parser Metadata (Sprint 4)

When recording flowchart generation, reuse existing `parserMetadata`:

```javascript
const result = FlowchartGenerator.generate(text, options);

AuditTrail.record('flowchart.generate', {
  projectId: project.id,
  userId: currentUser.id,
  actorCount: result.parsedData.parserMetadata.validationSummary.actors,
  activityCount: result.parsedData.parserMetadata.validationSummary.activities,
  decisionCount: result.parsedData.parserMetadata.validationSummary.decisions,
  documentCount: result.parsedData.parserMetadata.validationSummary.documents,
  parserMetadata: result.parsedData.parserMetadata,  // Full metadata
  snapshot: result.flowchart
});
```

### WCGW Detection Integration

```javascript
AuditTrail.record('wcgw.detect', {
  projectId: project.id,
  userId: currentUser.id,
  riskCount: detections.length,
  wcgwMetadata: { detectionIds: detections.map(d => d.id) }
});
```

## Validation Rules

1. `id` must be unique within each collection
2. `timestamp` must be valid ISO 8601
3. `source` must be one of: 'manual', 'rule-engine', 'ai', 'system'
4. `status` must be one of: 'active', 'deleted', 'restored'
5. `summary` must be non-empty string
6. `versionNumber` must be sequential per project
7. Snapshot only stored for: flowchart.generate, review.approve, review.reject
